---
title: "Outline Color"
---

Change the color of the outline.

```jsx
<div className={css({ outlineColor: 'blue.500' })} />
<div className={css({ ringColor: 'blue.500' })} /> // shorthand
```

| Prop           | CSS Property    | Token Category |
| -------------- | --------------- | -------------- |
| `outlineColor` | `outline-color` | `colors`       |
