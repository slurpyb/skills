# Writing Code

Focused, independently discoverable TypeScript skills.

## Skills

| Skill | Use it for |
| --- | --- |
| `writing-typescript` | Runtime implementation, external-data boundaries, results, state, dependencies, tests, and validation |
| `modeling-typescript-domains` | Entities, value objects, commands, outcomes, invariants, and lifecycle states |
| `designing-typescript-objects` | Interfaces, abstract classes, inheritance, factories, repositories, units of work, and mixins |
| `designing-typescript-types` | Generics, inference, conditional and mapped types, correlated contracts, utility types, and type tests |
| `documenting-typescript` | TSDoc, TypeDoc, exported contracts, examples, and documentation CI |
| `configuring-typescript` | `tsconfig`, package boundaries, declarations, targets, and compiler performance |
| `installing-typescript-anti-slop` | Bundled Oxlint policy installation and configuration |

`writing-typescript` remains the compatibility identity for ordinary implementation work. The other skills own specialist branches so they can evolve, be evaluated, and be invoked independently.

## Installation

```bash
claude plugin install writing-code@slurpyb-agent-skills
```
