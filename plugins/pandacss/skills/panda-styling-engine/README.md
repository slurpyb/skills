# Panda Styling Engine

A portable agent skill for routing Panda CSS work to the project-owned styling primitive, including React components built from standard recipes, slot recipes, and style context.

The skill surveys an active Panda MCP, classifies the request, loads only the matching reference, applies the current project vocabulary, and verifies extraction and styling boundaries.

`SKILL.md` is the entry point. `references/` contains progressively disclosed branches, `scripts/` contains deterministic checks, and `tests/` contains routing cases.
