# Introduction

This directory adapts the useful principles from William Strunk Jr.'s 1918 _The Elements of Style_ for current technical and professional writing.

The adaptation keeps concrete language, sound sentence structure, economical wording, and practical grammar. It removes outdated usage rules and modifies broad prescriptions when they would damage technical accuracy. In particular:

- meaning takes precedence over brevity;
- active voice requires a literal actor;
- negative wording remains when it defines behavior;
- singular “they” is standard;
- split infinitives are acceptable when they improve clarity;
- current project conventions take precedence over this reference.

Use these files as decision support, not as a mechanical checklist.
