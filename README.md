# Slurpyb skills and plugins

The repository is the stable marketplace for Codex and Cursor. Experimental and deprecated plugins have separate, explicitly selected marketplaces in `wip/` and `deprecated/`.

See [marketplace authoring, installation, and compatibility checks](docs/marketplaces.md). Full behavioral parity is a release requirement; the compatibility audit currently identifies unresolved migrations, and the release gate intentionally fails until they are addressed.
